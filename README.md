## Repository structure

- `design/brand/`: logo and brand collection concepts.
- `design/products/`: beverage packaging, alternate colors and viewing angles.
- `design/pages/`: website, shopping, account and support mockups.
- `design/archive/`: incomplete source images preserved for recovery.
- `design/exports/`: existing packaged design export.
- `design/manifest.json`: source filenames and SHA-256 checksums.
- `docs/`: project philosophy and completion roadmap.

## Development handoff

The design direction uses ivory, black, silver and flavor-specific accents, editorial headings, restrained product photography and clear ecommerce controls. Use one approved logo and a consistent product catalog across implementation. Final typography, spacing, responsive components, real prices, formulas, product measurements and business policies still need approval.

Brand artwork and source concepts are proprietary project materials. No open-source license is granted by this repository.
